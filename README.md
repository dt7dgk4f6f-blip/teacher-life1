# 先生ライフ — GitHub Pages版（Ver.3.6ベース）

中高一貫校の教員キャリアシミュレーション。既存のVer.3.6 HTMLを `index.html` として配置したGitHub Pages用パッケージです。

## 公開方法

1. GitHubで **Public** リポジトリ `teacher-life` を作成します。
2. このZIPを展開し、`index.html`、`README.md`、`.nojekyll` をリポジトリの最上位（ルート）にアップロードしてコミットします。**ZIPそのものをアップロードするだけでは公開できません。**
3. リポジトリの **Settings → Pages** で **Deploy from a branch** を選び、`main` / `/(root)` を指定して保存します。
4. 公開が完了したら `https://<GitHubユーザー名>.github.io/teacher-life/` にアクセスします（リポジトリ名が `teacher-life` の場合）。

## 遊び方・保存

- `index.html` はCSS・JavaScriptを内蔵しており、追加ライブラリは不要です。
- セーブデータはブラウザの `localStorage` に保存されます。端末・ブラウザを変えると自動では引き継がれません。ゲーム内のセーブ書き出し機能を使ってバックアップしてください。
- 既存のVer.3.6を元にしたため、複雑な人事・時間割ロジックの完全な整合性や、Windows/iPhone実機での動作は保証できません。
- 初回に画面が「起動しています…」から変わらない場合は、ブラウザの開発者ツール（F12）のConsoleに出るエラーを確認してください。

## ゲーム内の主要仕様（Ver.3.6ベース）

採用時の人事希望、役職選考試験、校長による辞令、授業担当・担任希望（お任せ対応）、中高兼任希望、役職別授業上限、学校イベント、年度更新、セーブ・復元など。

ゲーム内の学校設定・人事制度はフィクションとして調整したものです。実在校の正式な運用を示すものではありません。
